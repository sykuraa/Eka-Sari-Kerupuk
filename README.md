# Landing Page Kerupuk Eka Sari

Landing page resmi untuk **Kerupuk Eka Sari** — produsen kerupuk putih gurih, renyah, dan mekar sempurna.

---

## 🌟 Fitur & Perubahan Terbaru

1. **Foto Asli Kerupuk**: Menggunakan foto asli kerupuk putih di halaman utama (hero section) dan kartu produk (`assets/kerupuk.jpg`).
2. **Pilihan Produk Sederhana**:
   - **Kerupuk Putih (Besar)**: Tersedia pilihan **Matang** dan **Mentah**.
   - **Kerupuk Putih (Kecil)**: Tersedia pilihan **Matang** dan **Mentah**.
3. **Format Tanya & Pesan Cepat via WhatsApp**:
   - Angka/tabel harga telah dihapus sesuai arahan, digantikan dengan tombol direct order ke WhatsApp untuk menanyakan harga dan memesan sesuai jumlah (eceran, bal, atau karung).
4. **Halaman Bersih & Ringkas**:
   - Angka statistik (*bungkus terjual*, *mitra warung*, *kepuasan pelanggan*) telah dihapus.
   - Bagian *cerita dedikasi* telah dihapus agar halaman langsung fokus ke produk dan pemesanan.
   - Dilengkapi tips praktis menggoreng kerupuk mentah dan info pasokan warung/grosir.

---

## 🚀 Cara Melihat Hasil

1. Buka folder `c:\Users\USER\OneDrive\Dokumen\Eka sari`.
2. Klik dua kali pada file **`index.html`** untuk langsung melihat tampilannya di browser (Chrome / Edge / Firefox).

---

## ⚙️ Mengganti Nomor WhatsApp

Buka file `index.html` dengan text editor (misal Notepad atau VS Code):
- Cari nomor contoh `6281234567890`.
- Ganti dengan nomor WhatsApp aktif Anda (gunakan kode negara `62` tanpa tanda `+`, contoh: `6281298765432`).
- Simpan file `index.html`.
